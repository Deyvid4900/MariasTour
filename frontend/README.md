# Frontend MariaTour

Esta pasta representa a camada de apresentação do site.

- A interface principal fica em `index.html`
- O estilo está em `index.css`
- A lógica da página fica em `index.js`
- O painel administrativo fica em `admin/index.html`

O frontend se comunica com o backend em Node via API REST em `http://localhost:3000/api/excursions`.
